Alternativa manual

Se o agente nao estiver disponivel, corre directamente no WSL:
WSL_USER=operador bash ~/.local/bin/wsl_profile.sh export
O ficheiro sera guardado em /tmp/

Importar perfil

Para restaurar num outro PC, usa o menu Importar ou corre:
bash ~/.local/bin/wsl_profile.sh import --file profile.tar.gz
